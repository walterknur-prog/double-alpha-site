# Double Alpha Management website

Jekyll site on GitHub Pages for double-alpha.com. Owner: Walter Knur (wk@double-alpha.com).

- Brand: Double Alpha Management design system (sage #7FA88B / ink #1A1A1A, Inter, interwoven-alpha mark). Tokens live at the top of `assets/css/site.css`; don't add new hues.
- Voice: plain, direct, 12th-grade English. Numbers over adjectives. No hype. Name no clients.
- Two levels: level-1 pages are folders with `index.html`; level-2 pages come from `_services/`, `_experience/` and `_posts/`.
- New Substack posts: add a summary post in `_posts/` with `substack_url`, key points and a takeaway. Do not copy the full article.
- Always use `relative_url` for links so the site works with or without the custom domain.
